# GHzPrint - сборщик данных от P3-34
## Что делает
Данная программа читает csv файлы и собирает из них цельный xlsx файл
со страницами сырых данных и дополнительной
страницей таблицы готовой для обработки R-скриптом.
Все страницы сырых данных подписаны именем образца и номером заказа.
Таблица данных вычисляется по среднему от каждых 5 значений,
корректируя расчёт в зависимости от наличия ошибок коннекта.

## Как использовать
После запуска программа автоматически проводит поиск csv файлов за сегодня.
Если нужны файлы за другой день, то в поле даты можно ввести
дату в формате "дд.мм.гггг" и нажать "Повторить поиск".
Ниже выводится список найденных файлов, которые будут взяты в работу.
Для корректной работы программы имена файлов должны заканчиваться на "_ИмяОбразца",
обязательно с сохранением предыдущей части имени файла.
Если список файлов csv содержит все необходимые файлы, то можно нажимать "Создать .xlsx", что
сгенерирует соответствующий файл туда же, откуда запущена программа.

### Комментарии по сборке программы
Существует 2 варианта GUI программы:
* WALK - использует winAPI для отрисовки интерфейса, exe довольно мало весит.
* Fyne - использует кроссплатформенный отрисовщик через OpenGL,
но exe файл сильно больше весит.

После компиляции бинарник следует сжать через UPX, что уменьшит его размер в ~3 раза:
* WALK 8.42 → 2.51 Мб
* Fyne 26.0 → 9.67 Мб
